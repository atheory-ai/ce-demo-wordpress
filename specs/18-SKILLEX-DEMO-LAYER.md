# 18 Skillex Demo Layer

## Goal

Add Skillex only as procedural guidance, separate from CE's source and semantic
evidence.

## Required content

If Skillex is included, provide a versioned package containing short skills for:

- WordPress hook/filter investigation;
- Gutenberg data-store and REST reasoning;
- WooCommerce checkout/Store API investigation;
- source-grounded uncertainty reporting; and
- benchmark operation and evaluation.

Skills must not contain the expected answers, cached source facts, or hidden
semantic fixtures. CE supplies resolved source knowledge; Skillex supplies a
repeatable reasoning procedure.

## Evaluation design

Report three distinct conditions when practical:

| Condition | Purpose |
| --- | --- |
| baseline | Ordinary source discovery only. |
| CE | Indexed/semantic CE without Skillex. |
| CE + Skillex | CE plus procedural domain guidance. |

Do not attribute a Skillex-derived checklist benefit to IIR or source lifting.

## Acceptance criteria

- `skillex.yaml` and skill sources are present only on `ce`.
- Every skill has a stated scope, version, and evaluation rationale.
- A run report identifies which skills were active.
